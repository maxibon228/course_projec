# stage_5_admin

Учебный Python-проект с Flask-сервером и административной панелью на `tkinter`.

Проект позволяет отправлять сообщения через веб-форму, сохранять их в `messages.csv` в зашифрованном виде и просматривать сообщения через административную панель.

## Главное обновление stage_5_admin

В `stage_5_admin` добавлена пасхалка для веб-формы.

Если пользователь вводит в форме слово:

```text
Чай
```

то обычная логика сохранения сообщения не выполняется.

Сообщение `Чай`:

- не шифруется;
- не сохраняется в `messages.csv`;
- не открывает страницу `saved.html`.

Вместо этого открывается страница `easter.html`, на которой отображается:

```text
Пасхалка
Вы на верном этапе
ссылка на тг бота
Отправить снова
```

Кнопка **«Отправить снова»** возвращает пользователя обратно на форму отправки сообщения:

```text
http://127.0.0.1:5000/70193935
```

## Описание файлов

### cypher.py

Модуль шифрования и дешифрования сообщений.

Содержит функции:

```python
def encrypt(message, sid=70193935):
    ...

def decrypt(message, sid=70193935):
    ...
```

Использует шифр Цезаря.

Сдвиг вычисляется по формуле:

```python
shift = sid % 11
```

Для студенческого ID `70193935` сдвиг равен `9`.

---

### srv.py

Flask-сервер проекта.

Основной маршрут:

```text
/70193935
```

Поддерживает:

- `GET` — показывает форму отправки сообщения;
- `POST` — принимает сообщение из формы.

Если сообщение не равно `Чай`, сервер:

1. шифрует текст через `cypher.encrypt`;
2. сохраняет запись в `messages.csv`;
3. открывает `saved.html`;
4. показывает кнопку **«Отправить снова»**.

Если сообщение равно `Чай`, сервер:

1. не сохраняет сообщение;
2. не шифрует сообщение;
3. открывает страницу `easter.html`;
4. показывает пасхалку и кнопку **«Отправить снова»**.

Дополнительные маршруты:

```text
/get_all.json
```

Возвращает все сообщения из `messages.csv` в формате JSON. Текст сообщений возвращается в расшифрованном виде.

```text
/reset
```

Очищает файл `messages.csv`.

---

### admin.py

Административная панель на `tkinter`.

Функции админ-панели:

- открыть файл `messages.csv`;
- создать новый CSV-файл, если он отсутствует;
- показать таблицу сообщений;
- расшифровать текст для отображения;
- добавить новое сообщение;
- удалить выбранное сообщение;
- переместить сообщение вверх;
- переместить сообщение вниз;
- перечитать файл через кнопку **Обновить**.

При добавлении сообщения через админ-панель:

- создаётся новый `id`;
- ставится текущее время;
- `ip = admin`;
- текст шифруется;
- запись сохраняется в `messages.csv`.

---

### messages.csv

Файл хранения сообщений.

Формат строки:

```text
id,datetime,ip,text
```

Важно:

- текст в CSV хранится только в зашифрованном виде;
- в админ-панели текст показывается расшифрованным;
- в `/get_all.json` текст показывается расшифрованным;
- сообщение `Чай`, отправленное через веб-форму, в CSV не сохраняется.

## Установка зависимостей

Для работы сервера нужен Flask:

```bash
pip install flask
```

Если используется `requirements.txt`, можно выполнить:

```bash
pip install -r requirements.txt
```

## Запуск сервера

```bash
python srv.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:5000/70193935
```

## Обычная отправка сообщения

1. Открыть страницу:

```text
http://127.0.0.1:5000/70193935
```

2. Ввести любой текст, кроме `Чай`.
3. Нажать **«Отправить»**.
4. Сообщение сохранится в `messages.csv` в зашифрованном виде.
5. Откроется страница `saved.html`.
6. На странице будет кнопка **«Отправить снова»**.

## Проверка пасхалки

1. Открыть страницу:

```text
http://127.0.0.1:5000/70193935
```

2. Ввести:

```text
Чай
```

3. Нажать **«Отправить»**.
4. Откроется страница `easter.html`.
5. Сообщение `Чай` не будет сохранено в `messages.csv`.
6. На странице будет кнопка **«Отправить снова»**.

## Получение всех сообщений в JSON

Открыть:

```text
http://127.0.0.1:5000/get_all.json
```

Сервер вернёт список сообщений. Текст сообщений будет расшифрован.

## Очистка messages.csv

Открыть:

```text
http://127.0.0.1:5000/reset
```

Файл `messages.csv` будет очищен.

## Общая схема работы

Обычное сообщение:

```text
Пользователь → Flask form → srv.py → encrypt() → messages.csv → saved.html
```

Пасхалка:

```text
Пользователь → Flask form → вводит "Чай" → srv.py → easter.html
```

Админ-панель:

```text
Администратор → admin.py → decrypt() → таблица сообщений
```

## Требования

- Python 3.8+.
- Flask.

- csv.
- string.

## Ограничения проекта

- Не используется база данных.
- Все обычные сообщения хранятся в `messages.csv`.
- Текст в CSV хранится только в зашифрованном виде.
- В интерфейсе и JSON текст отображается расшифрованным.
- Сервер и админ-панель работают с одним и тем же файлом `messages.csv`.
- Сообщение `Чай` через веб-форму не сохраняется.
- Пути к файлам относительные.
