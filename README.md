# Stage 4 — Административная GUI-панель

## Назначение
`admin.py` управляет файлом `messages.csv`: показывает таблицу с расшифрованным текстом, добавляет записи с `ip = admin`, удаляет и перемещает строки. `srv.py` использует тот же CSV-файл.

## Установка Flask для сервера
```bash
pip install -r requirements.txt
```

## Запуск сервера
```bash
python srv.py
```

## Запуск админки
```bash
python admin.py
```

## Тесты
```bash
python -m unittest -v
```

## Проверка вручную
1. Запустить `srv.py`.
2. Запустить `admin.py`.
3. Выбрать `messages.csv`.
4. Добавить сообщение в браузере через `/70193935`.
5. Нажать «Обновить» в админке.
6. Проверить, что запись появилась в таблице.

## Отладка
- проверено создание отсутствующего CSV;
- проверено шифрование текста при сохранении;
- проверена расшифровка при отображении;
- проверены кнопки вверх/вниз/удалить;
- проверено добавление с `ip = admin`.
