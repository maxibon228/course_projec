## Доступные алгоритмы

- `caesar` — **Цезарь**, классический сдвиг.
- `atbash` — **Атбаш**, зеркальная замена.
- `vigenere` — **Виженер**, полиалфавитный шифр с учебным ключом `cipherweb`.

## Формат messages.csv

Новый формат строки:

```text
id, datetime, ip, algorithm, text
```

Где:

- `id` — номер сообщения;
- `datetime` — дата и время сохранения;
- `ip` — IP-адрес отправителя или `admin`;
- `algorithm` — ID алгоритма, например `caesar`, `atbash`, `vigenere`;
- `text` — зашифрованный текст.

Старый формат тоже поддерживается:

```text
id, datetime, ip, text
```

Если сервер видит старую строку из 4 полей, он считает, что она была зашифрована алгоритмом `caesar`.

## Как добавить новый шифр

В `cypher.py` нужно создать две функции и зарегистрировать алгоритм через `register_algorithm(...)`:

```python
def reverse_encrypt(message, sid=70193935):
    return message[::-1]


def reverse_decrypt(message, sid=70193935):
    return message[::-1]


register_algorithm(
    "reverse",
    "Реверс",
    reverse_encrypt,
    reverse_decrypt,
    description="Переворот строки",
    icon="↔",
)
```

После перезапуска сервера новый шифр автоматически появится:

- в выпадающем списке формы;
- в статистике справа;
- в JSON;
- в `admin.py`.
