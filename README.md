# Stage 3 — Flask веб-сервис

## Назначение
Сервер `srv.py` принимает сообщения через HTML-форму, шифрует их через `cypher.py`, сохраняет в `messages.csv` и отдаёт JSON-выгрузку с расшифрованными текстами.

## Установка Flask
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python srv.py
```

Адреса:
- `http://127.0.0.1:5000/70193935`
- `http://127.0.0.1:5000/reset`
- `http://127.0.0.1:5000/get_all.json`

## Тесты
```bash
python -m unittest -v
```

## Отладка
- проверена папка `templates`;
- проверена запись CSV в 4 поля;
- проверен `/reset`;
- проверен `/get_all.json`;
- в CSV текст хранится зашифрованным, а в JSON возвращается расшифрованным.
