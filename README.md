# Stage 1 — Модуль шифрования

## Назначение
Этап реализует файл `cypher.py` с функциями `encrypt()` и `decrypt()`.
Для ID `70193935` используется сдвиг `70193935 % 11 = 9`.

## Запуск
```bash
python cypher.py
```

После запуска создаются/обновляются файлы:
- `encrypt_result.txt`;
- `decrypt_result.txt`.

## Тесты
```bash
python -m unittest -v
```

## Отладка
- проверена формула сдвига;
- проверен порядок символов алфавита;
- проверено, что `if __name__ == "__main__"` не запускается при импорте;
- проверена запись результатов в файлы.
