# 🔐 Cipher Web 4.2 — Атбаш и переключение темы

Учебный Flask-проект курсовой работы по теме **шифрования сообщений**.

Версия **`4_2_cipherweb_FIXED_atbash_theme`** является развитием проекта **`stage_6`**. В этой версии приложение стало не просто простой web-формой с CSV и админкой, а полноценной web-панелью Cipher Web с современным интерфейсом, выбором алгоритма шифрования, поддержкой Атбаша и переключением тёмной/светлой темы.

Студенческий ID проекта: **70193935**.

---

## ✨ Что изменилось по сравнению со `stage_6`

### 1. Новый web-интерфейс

В `stage_6` web-часть была простой HTML-формой.

В версии `4_2_cipherweb_FIXED_atbash_theme` добавлен полноценный dashboard:

* общий шаблон `templates/base.html`;
* левая боковая панель Cipher Web;
* верхняя панель управления;
* карточка отправки сообщения;
* карточки статистики;
* таблица сохранённых сообщений;
* поиск по сообщениям;
* кнопка перехода к JSON;
* визуальные статусы сообщений.

Интерфейс получил тёмный современный стиль с градиентами, скруглениями и glassmorphism-оформлением.

---

### 2. Добавлены CSS и JavaScript

В `stage_6` отдельной папки `static/` не было.

В версии 4.2 появилась новая структура:

```text
static/
├── css/
│   └── style.css
└── js/
    └── main.js
```

`style.css` отвечает за внешний вид:

* тёмную тему;
* светлую тему;
* карточки dashboard;
* sidebar;
* таблицу сообщений;
* кнопки, бейджи и анимации.

`main.js` отвечает за поведение интерфейса:

* счётчик символов в textarea;
* поиск по таблице сообщений;
* плавное появление карточек.

---

### 3. Добавлено переключение тёмной и светлой темы

В новой версии появилась круглая кнопка с луной в верхней панели.

Она переключает сайт между режимами:

* тёмная тема;
* светлая тема.

Выбранная тема сохраняется в браузере через `localStorage`, поэтому после обновления страницы выбранный режим остаётся прежним.

В левом верхнем блоке интерфейса есть контрольная метка:

```text
v4.2 · Атбаш · светлая тема
```

Если этой метки нет, значит запущена старая папка проекта или браузер показывает старую страницу из кэша.

---

### 4. Добавлен выбор алгоритма шифрования

В `stage_6` использовался только шифр Цезаря.

В версии 4.2 в форме появился выпадающий список **«Алгоритм»**.

Доступны два варианта:

| Алгоритм | ID       | Описание                                         |
| -------- | -------- | ------------------------------------------------ |
| Цезарь   | `caesar` | Классический шифр со сдвигом по студенческому ID |
| Атбаш    | `atbash` | Зеркальная замена символов по общему алфавиту    |

Пользователь выбирает алгоритм перед отправкой сообщения.

---

### 5. Добавлен шифр Атбаш

В `cypher.py` появилась новая логика:

* старые функции `encrypt()` и `decrypt()` сохранены для совместимости;
* добавлены отдельные функции для Цезаря;
* добавлены функции `atbash_encrypt()` и `atbash_decrypt()`;
* создан словарь `ALGORITHMS` для хранения доступных алгоритмов.

Теперь архитектура шифров стала расширяемой.

Чтобы добавить новый алгоритм в будущем, нужно:

1. написать функцию шифрования;
2. написать функцию расшифровки;
3. добавить запись в `ALGORITHMS`.

Пример структуры:

```python
def new_encrypt(message, sid=70193935):
    ...


def new_decrypt(message, sid=70193935):
    ...


ALGORITHMS = {
    "caesar": {
        "title": "Цезарь",
        "encrypt": caesar_encrypt,
        "decrypt": caesar_decrypt,
    },
    "atbash": {
        "title": "Атбаш",
        "encrypt": atbash_encrypt,
        "decrypt": atbash_decrypt,
    },
}
```

### 6. Изменён формат `messages.csv`

В `stage_6` CSV имел формат:

```text
id,datetime,ip,text
```

В версии 4.2 появился новый формат:

```text
id,datetime,ip,algorithm,text
```

Теперь вместе с сообщением сохраняется ID алгоритма, которым оно было зашифровано.

Пример:

```text
1,2026-06-08 12:49:44,127.0.0.1,atbash,"зашифрованный текст"
```

При этом сохранена обратная совместимость.

Старые строки из `stage_6`, где только 4 поля, продолжают читаться. Такие сообщения автоматически считаются зашифрованными алгоритмом `caesar`.

### 8. Обновлена работа после отправки сообщения

В `stage_6` после отправки обычного сообщения открывался шаблон `saved.html`.

В версии 4.2 используется более современный сценарий:

1. пользователь отправляет форму;
2. сообщение шифруется выбранным алгоритмом;
3. запись добавляется в `messages.csv`;
4. Flask показывает flash-уведомление;
5. пользователь возвращается на dashboard.

Пасхалка со словом `Чай` сохранена.

Если ввести:

```text

```

сообщение не будет сохранено, а откроется `easter.html`.

## 🔐 Поддерживаемые алгоритмы

### Цезарь

Классический шифр со сдвигом.

Сдвиг вычисляется по студенческому ID:

```python
shift = sid % 11
```

Для ID `70193935` сдвиг равен:

```text
9
```

### Атбаш

Атбаш заменяет каждый символ на зеркальный символ из общего алфавита.

Особенность Атбаша:

```text
шифрование = расшифровка
```

То есть одна и та же операция используется и для шифрования, и для обратного преобразования.

## 🧩 Как добавить новый шифр

Открой `cypher.py`.

Добавь функции нового алгоритма:

```python
def reverse_encrypt(message, sid=70193935):
    return message[::-1]


def reverse_decrypt(message, sid=70193935):
    return message[::-1]
```

Затем зарегистрируй его в `ALGORITHMS`:

```python
ALGORITHMS = {
    "caesar": {
        "title": "Цезарь",
        "encrypt": caesar_encrypt,
        "decrypt": caesar_decrypt,
    },
    "atbash": {
        "title": "Атбаш",
        "encrypt": atbash_encrypt,
        "decrypt": atbash_decrypt,
    },
    "reverse": {
        "title": "Реверс",
        "encrypt": reverse_encrypt,
        "decrypt": reverse_decrypt,
    },
}
```

После перезапуска сервера новый алгоритм появится в выпадающем списке, если интерфейс получает список через `get_available_algorithms()`.
