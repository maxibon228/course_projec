# Stage 2 — GUI-интерфейс на tkinter

## Назначение
Приложение `app.py` открывает зашифрованный txt-файл, расшифровывает строки через `cypher.py`, позволяет добавить новые строки и сохранить файл обратно в зашифрованном виде.

## Запуск
```bash
python app.py
```

## Тесты
```bash
python -m unittest -v
```

## Проверка вручную
1. Нажать «Загрузить файл» и выбрать `encrypt.txt`.
2. Проверить отображение расшифрованных строк.
3. Ввести новую строку в нижнее поле.
4. Нажать «Добавить».
5. Нажать «Зашифровать и сохранить».

## Отладка
- проверена валидация недопустимых символов;
- проверена загрузка и расшифровка txt;
- проверено сохранение в зашифрованном виде;
- используется только `grid`, без смешивания с `pack`.
